# API リファレンス

## 概要

現在の実装では、Flask バックエンドはシンプルな静的ファイル配信とテンプレートレンダリングのみを提供します。
REST API エンドポイントは存在しません。

---

## エンドポイント一覧

### `GET /`

アプリケーションのメインページを返します。

**レスポンス**

| ステータスコード | Content-Type | 説明 |
|---|---|---|
| `200 OK` | `text/html` | `index.html` テンプレートをレンダリングして返す |

**例**

```bash
curl http://localhost:5000/
```

---

### 静的ファイル

Flask の静的ファイル配信機能により、以下のパスでリソースが提供されます。

| パス | 内容 |
|---|---|
| `GET /static/js/timerLogic.js` | タイマーのピュアロジックモジュール |
| `GET /static/js/timer.js` | タイマーの DOM コントローラモジュール |
| `GET /static/css/style.css` | アプリケーションのスタイルシート |

---

## 未実装のエンドポイント

`features.md` に記載されている以下の機能は現時点では実装されていません。

- ユーザー設定の保存・読み込み API
- セッション履歴の保存・読み込み API

設定とセッション数のデータはすべてブラウザの `localStorage` で管理されます。詳細は [data-models.md](./data-models.md) を参照してください。
